# Stock Scorecard (Yahoo Finance backend)

## Run locally
npm install && npm start   -> open http://localhost:3000

## Deploy free (Render.com)
1. Push this folder to a GitHub repo.
2. Render -> New -> Web Service -> pick the repo.
3. Build command: npm install   |   Start command: npm start
4. Open the https URL it gives you. On phone: Add to Home Screen.

## APK
Go to pwabuilder.com, paste your Render URL, choose Android, download the package.
